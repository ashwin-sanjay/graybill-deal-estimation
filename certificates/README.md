# Numerical and symbolic evidence

The suite uses three complementary calculations:

- `Certificate0001`: exact symbolic identities for the eight-tent construction.
- `Certificate0002`: exact rational verification of the two-stage descent and the fixed-seed packet floor at design (2,2).
- `Certificate0003`: directed double-Haar enclosures, exact positive-simplex arithmetic, finite-continuum interpolation and two finite wall-cover checks at design (11,11).

The statistical integral arguments and hypotheses are in the [written proofs](../docs/Proofs.md). These computations establish their specified finite or symbolic claims; the input intervals carry the role described below.

## Run the finite suite

Install the pinned packages in a separate Python environment, then run from the release root:

```sh
python -m pip install -r certificates/requirements.txt
python -B tools/verify_certificates.py --work /absolute/path/outside/release/new-certificate-work
```

The work directory must be empty and outside the release. The checker copies only the current certificate sources/data and the analytic wall proof, then records current source hashes, package versions, commands, outcomes and logs. It freshly generates the rational artifact, normalized charge columns and continuum certificate, comparing their complete mathematical payloads to the supplied data. The rational artifact records the executing Python version; this environment field is reported separately from mathematical equality. Exact artifact replay and four auxiliary regressions follow generation. Two negative controls reject an altered retained payload and a false current-producer claim.

## Retained directed inputs

`Certificate0003/Data0001.json` through `Data0005.json`, `Data0007.json` and `Data0009.json` contain retained directed enclosures. Their interval endpoints, grids, error ledgers, numerical constants and cell/node ordering were compared exactly to the archived accepted inputs during packaging. The original producer bindings were checked before migration. These intervals were **not regenerated by the renamed producers**. Their retained timing fields describe the original enclosure computations.

Each such file marks this scope in `retainedEnclosure`. [Inputs.json](Certificate0003/Inputs.json) authenticates the current dataset and checking-source identities. [Script0012.py](Certificate0003/Script0012.py) distinguishes this explicit retained-input mode from freshly generated producer outputs. It never substitutes a current producer hash for a historical generation claim. Historical source paths and the private transformation correspondence are outside this distribution.

The wall analytic subsection remains byte-identical and independently pinned by the checkers. Both wall checkers retain the exact range, dyadic routing, interval serialization, positive lower bounds, arithmetic ledger and cover checks. The separate checker imports no numerical producer.

## Recompute the directed enclosures

Use a disposable copy of the release. From its root, the five charge inputs can be regenerated as follows (each invocation is a separate computation):

```sh
python -B certificates/Certificate0003/Script0002.py --eta 11/10 --batch 4 --output certificates/Certificate0003/Data0001.json
python -B certificates/Certificate0003/Script0002.py --eta 2 --batch 4 --output certificates/Certificate0003/Data0002.json
python -B certificates/Certificate0003/Script0002.py --eta 11/2 --batch 4 --output certificates/Certificate0003/Data0003.json
python -B certificates/Certificate0003/Script0002.py --eta 18 --batch 4 --output certificates/Certificate0003/Data0004.json
python -B certificates/Certificate0003/Script0002.py --eta 145 --batch 4 --output certificates/Certificate0003/Data0005.json
python -B certificates/Certificate0003/Script0003.py
python -B certificates/Certificate0003/Script0005.py --workers 2 --output certificates/Certificate0003/Data0007.json
python -B certificates/Certificate0003/Script0006.py certificates/Certificate0003/Data0007.json --output certificates/Certificate0003/Data0008.json
python -B certificates/Certificate0003/Script0009.py --workers 2 --max-depth 4 --output certificates/Certificate0003/Data0009.json
```

These producers record their actual current source hashes. The finite checkers require those hashes for newly generated files. Run the full finite suite on that disposable copy afterward. Integral regeneration and finite consequence checks are distinct computations; the recorded finite-suite result does not claim that the commands in this section were executed.
